# Survey Application

This repository contains a web-based survey application developed for an academic research project.

The application provides a digital questionnaire flow, backend processing, scoring logic, and export functionality for collected survey responses.

## Project Purpose

The project was created to support the collection and processing of questionnaire data in an academic context.

It includes:

* A web-based questionnaire interface
* Backend endpoints for submitting responses
* Scoring logic for standardized questionnaire data
* Export functionality for collected responses

## Tech Stack

* Java
* Spring Boot
* HTML
* CSS
* JavaScript
* GitHub for version control
* Railway was previously used for deployment

## Main Features

* Digital survey flow
* Form submission handling
* Backend validation and processing
* Score calculation
* CSV/JSON export support

## Project Status

This project is no longer actively maintained.

The previous Railway deployment has been stopped, and the application is no longer hosted online.
The repository remains available as a source-code reference.

## Notes

This project was developed for academic purposes only.
It is not intended for production use or for collecting new data.
